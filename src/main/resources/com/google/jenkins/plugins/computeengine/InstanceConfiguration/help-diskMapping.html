Specify additional disks to attach to the instance, using GCP key=value format. One disk per line. Supports both creating new disks and attaching existing disks.

Create new disk (--create-disk semantics)

When the line contains source-snapshot, size, or type, a new disk is created and attached. At least one of source-snapshot or size is required.

  • source-snapshot — Snapshot name, relative path (e.g. projects/{project}/global/snapshots/{name}), or full resource URI (e.g. https://compute.googleapis.com/compute/v1/projects/{project}/global/snapshots/{name}). Use just the name for snapshots in the same project.
  • size — Disk size in GB. Required for blank disks; optional when a source is specified (defaults to the source snapshot size).
  • type — Disk type: short name (e.g. pd-ssd), relative path (e.g. zones/us-east1-b/diskTypes/pd-ssd), or full resource URI. Short names are automatically qualified to the instance's zone. Defaults to pd-standard.
  • name — Name for the new disk. If omitted, GCP generates a name automatically.
  • device-name — Device name shown in the guest OS.
  • description — Optional description for the disk.
  • mode — ro for read-only or rw for read-write (default: rw).
  • interface — SCSI or NVME.
  • auto-delete — yes or no (default: yes).

Attach existing disk (--disk semantics)

When the line contains only name (without any create-disk keys), an existing disk is attached by reference.

  • name — Existing disk name, relative path, or full resource URI (required). Use just the name for zonal disks in the same zone; use a relative path or full resource URI for regional or cross-project disks (e.g. projects/myproject/regions/us-central1/disks/my-regional-disk).
  • device-name — Device name shown in the guest OS.
  • mode — ro for read-only or rw for read-write (default: rw). Use ro when multiple instances may attach the same disk.
  • interface — SCSI or NVME.
  • auto-delete — yes or no (default: yes).

Examples:

source-snapshot=my-cache-snapshot
source-snapshot=my-data-snapshot,size=100,type=pd-ssd,auto-delete=no
source-snapshot=https://compute.googleapis.com/compute/v1/projects/other-project/global/snapshots/shared-cache,size=50,type=pd-balanced
size=200,type=pd-ssd,name=scratch-disk
name=shared-data-disk,mode=ro
name=projects/other-project/zones/us-east1-b/disks/team-data,mode=ro,auto-delete=no

Cross-project resources: Snapshots are global resources in GCP. To use a snapshot from a different project, specify a relative path (e.g. projects/{project}/global/snapshots/{name}) or the full resource URI from the Compute API (e.g. https://compute.googleapis.com/compute/v1/projects/{project}/global/snapshots/{name}). To attach an existing disk from a different project or region, use its relative path or full resource URI. The configured service account must have appropriate IAM permissions on the source project.

Mounting disks inside the VM must be done via the startup script. Leave empty to not attach any additional disks.
